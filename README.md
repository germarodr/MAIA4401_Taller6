# MAIA 4401 - Taller 6

Workspace para el laboratorio de APIs de prediccion del modelo BankChurn.

## Preparacion

Este directorio es un repositorio independiente para conectar con un repositorio nuevo de GitHub.

```bash
git init
git add .
git commit -m "Inicializar workspace del Taller 6"
```

Despues de crear el repositorio vacio en GitHub Web, asociarlo y publicar el contenido:

```bash
git remote add origin <URL_DEL_REPOSITORIO>
git branch -M main
git push -u origin main
```

## Estructura esperada

El proyecto del taller debe quedar con la API en la raiz del repositorio:

```text
MAIA4401_Taller6/
├── app/
├── model-pkg/
├── requirements.txt
├── test_requirements.txt
├── typing_requirements.txt
├── tox.ini
└── Procfile
```

El reporte del taller y las evidencias pueden mantenerse en este mismo repositorio.
